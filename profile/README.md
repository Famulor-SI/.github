## Build with Famulor

| Tool | What it does | Start here |
| --- | --- | --- |
| **Famulor Skill** | Lets Claude Code, Codex, Cursor, Gemini CLI and OpenClaw build and improve your Famulor assistants. | [Famulor-Skill](https://github.com/Famulor-SI/Famulor-Skill) |
| **MCP server** | Connects any MCP client to your workspace at `https://app.famulor.io/mcp`. | [Docs](https://docs.famulor.io/mcp/overview) |
| **Cursor plugin** | Reads your assistants and conversation history in Cursor. | [famulor-mcp-plugin](https://github.com/Famulor-SI/famulor-mcp-plugin) |
| **CLI** | Runs every REST API operation as a command: `npx famulor`. | [Docs](https://docs.famulor.io/cli/overview) |
| **TypeScript SDK** | Calls the Famulor API from your code: `npm install famulor-sdk`. | [Docs](https://docs.famulor.io/sdk/overview) |
| **REST API** | Manages assistants, calls, campaigns and conversations. | [API reference](https://docs.famulor.io/api-reference/introduction) |
| **n8n and Zapier** | Start workflows from calls and messages. | [n8n](https://docs.famulor.io/automations/n8n) · [Zapier](https://docs.famulor.io/automations/zapier) |

### Quick start

Give your coding agent the Famulor Skill:

```bash
npx skills add Famulor-SI/Famulor-Skill --skill famulor-skill
```

Then ask it to build an assistant, for example: *"Create a phone receptionist for my dental practice that books appointments."*
