# Security

Report vulnerabilities in any Famulor-SI repository or in the Famulor service privately to **support@famulor.io** with the subject “Security”. Include the affected repository or product, a minimal redacted reproduction and the possible impact.

Don't open a public issue for a vulnerability, and never post credentials, tokens, customer data or conversation content. If you find an exposed Famulor API key, revoke it in your workspace right away.

Repositories with their own `SECURITY.md` add rules for their content; this file applies to all others.
